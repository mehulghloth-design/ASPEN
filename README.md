# ASPEN — AI Procurement Intelligence Platform

ASPEN is a modern, minimalistic, AI-first procurement intelligence platform for Indian Bureau of Standards (BIS) compliance, natural language requirement parsing, and role-based procurement management.

## Features
- **Natural Language Search**: Central NLU bar parses procurement requirements to match official Indian Standards (IS codes).
- **Role-Based Workspaces**: Customized perspectives for Guest Users, Buyers (Government/PSU Officers), Sellers (Manufacturers), and Administrators.
- **BIS Standards Directory**: Comprehensive national standards database with manufacturer compliance verification protocols.
- **Page Navigation & Back History**: Dynamic back button support and smooth view transitions.
